 Python Web Scraping Project

📌 About the Project

This project demonstrates web scraping using Python to extract book titles and prices from a sample website.

🚀 Features

- Extracts book titles from a website.
- Collects book prices.
- Parses HTML content.
- Displays the extracted information.

🛠️ Technologies Used

- Python
- Requests
- BeautifulSoup
- Google Colab

📚 Concepts Learned

- HTTP Requests
- HTML Parsing
- Data Extraction
- Python Libraries
- Web Scraping Fundamentals

▶️ How to Run

1. Open the project notebook in Google Colab.
2. Install the required libraries:
   "!pip install requests beautifulsoup4"
3. Run the notebook cells.
4. View the extracted book titles and prices.

🎯 Project Objective

The objective of this project is to understand web scraping and learn how to collect structured information from a website using Python.
